# Data Structures and Algorithms

## Overview
A comprehensive collection of custom data structures and algorithmic solutions built from scratch. This repository demonstrates strong foundational knowledge of computational logic, object-oriented programming, strict memory management, and dynamic expression parsing.

## Tech Stack
* **Languages:** C++, C#
* **Paradigms:** Object-Oriented Programming (OOP), Procedural Programming

## Key Implementations
* **Custom Data Structures (C++):** Development of Stacks, Linked Lists, Binary Search Trees (BST), and Hash Tables without relying on standard container libraries.
* **Math Expression Parser (C#):** A custom string evaluator that tokenizes raw user input and dynamically resolves complex mathematical operations, strictly enforcing operator precedence without relying on built-in `eval()` functions.
* **Quadratic Equation Solver (C#):** An OOP-based mathematical solver featuring rigorous edge-case handling, utilizing nullable types and discriminant evaluation to safely compute both real and complex roots.
* **Mastermind Logic Engine (C++):** Algorithmic implementation of the classic code-breaking game, demonstrating pattern matching, complex state evaluation, and conditional logic structures.
* **Algorithmic Optimization:** Consistent focus on algorithmic time complexity, safe memory allocation, and robust input validation.
